# Project instructions

## GitHub synchronization

- This project is linked to https://github.com/battick/about-me.git (origin), with main as the initial branch.
- The user requests that after completing each requested project change and appropriate validation, commit the task changes and push them to the corresponding branch on origin. This is standing authorization; do not ask again for routine commits or pushes.
- Commit only changes belonging to the task. Keep credentials, tokens, local environment files, and unrelated user changes out of commits.
- Use normal pushes. If remote changes conflict, preserve both sides and resolve safely; never force-push without explicit authorization.
- If local Git authentication is unavailable, use the connected GitHub tools when practical and keep the local checkout consistent with the remote. If synchronization cannot complete, clearly report that changes remain local.
- Report the resulting commit and synchronization status when finishing a change.
- Synchronization happens after an assistant completes a task; this does not install a background file watcher or upload changes made outside assistant tasks automatically.
